## 📋 Sobre o Projeto

O **Sistema de Clínica Médica** é uma aplicação web desenvolvida em Java utilizando a arquitetura trabalhada em sala de aula, com interface baseada no template **Manhattan** e componentes **PrimeFaces**.

O objetivo é auxiliar no gerenciamento básico de uma clínica médica, permitindo o controle de médicos, pacientes e consultas de forma organizada e prática.

> 🎓 Projeto desenvolvido individualmente como **trabalho final de disciplina**.

---

## ✨ Funcionalidades

| Funcionalidade | Descrição |
|---|---|
| 👨‍⚕️ Cadastro de médicos | Registro e gestão do corpo clínico |
| 🧑‍💼 Cadastro de pacientes | Gerenciamento do cadastro de pacientes |
| 📅 Agendamento de consultas | Marcação de novas consultas |
| ❌ Cancelamento de consultas | Cancelamento de consultas agendadas |
| 📋 Listagem de consultas | Visualização de todas as consultas agendadas |

---

## 🛠️ Tecnologias

- **Java EE** — backend e lógica de negócio
- **PrimeFaces** — componentes de interface
- **JPA / Hibernate** — persistência de dados
- **Template Manhattan** — layout da aplicação
- **Arquitetura MVC** — organização do projeto

## Modelo Entidade-Relacionamento

O banco é composto por 3 entidades principais:
- **MEDICO** — cadastro do corpo clínico
- **PACIENTE** — cadastro de pacientes
- **CONSULTA** — relaciona médico e paciente com data, status e observação
